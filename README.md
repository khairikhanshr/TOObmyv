# LOVE — Anantara The Palm

Адаптивный лендинг туристического продукта ТОО «LOVE».

Сайт: https://khairikhanshr.github.io/TOObmyv/

## Публикация

GitHub Pages публикует корень ветки `main`. Сайт написан на HTML, CSS и JavaScript, сборка и установка зависимостей не нужны. Фотографии предоставлены заказчиком.

Локальный просмотр: `python3 -m http.server 4173`.

Даты поездки: 12–17 октября 2026 года. Возвращение в Алматы — 18 октября в 02:45. Год выбран по текущей дате задания. В адресе исправлено противоречие: Palm Jumeirah находится в Дубае, а не в Абу-Даби.

## Приём заявок — требуется контакт владельца

GitHub Pages не обрабатывает формы на сервере. В `app.js` предусмотрен `BOOKING_ENDPOINT` для подключённого HTTPS-сервиса приёма заявок с поддержкой FormData и CORS. Сейчас он пуст: форма проверяет поля, но не отправляет и не сохраняет персональные данные; пользователю явно сообщается, что приём заявок не подключён. Сообщение об успешной отправке отображается только после успешного ответа сервиса.

Чтобы завершить подключение, владелец должен предоставить адрес существующего сервиса приёма заявок либо рабочий email/WhatsApp менеджера для выбора соответствующего способа отправки. Не добавляйте API-ключи в публичный JavaScript. Перед запуском проверьте реальную доставку тестовой заявки и настройки защиты от спама на стороне выбранного сервиса.

## Возможности

- Мобильное меню и переходы по разделам.
- Галерея номера и просмотр увеличенного фото; закрытие клавишей Escape.
- Адаптивная компоновка и поддержка reduced motion.
- Постоянная кнопка бронирования, скрывающаяся возле самой формы.
- Валидация имени, телефона, email и согласия на обработку заявки.
- Все изображения находятся в `assets/`; шрифты загружаются из Google Fonts с системным запасным вариантом.
